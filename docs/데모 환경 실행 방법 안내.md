# Zero-Leak 데모 환경 실행 방법 안내

내 PC에서 모델·API 키 없이 전체 데모를 돌리는 방법입니다. 판단은 규칙 기반 `mock` 모드로 하며,
발표 흐름(유출 알림 → 일괄 처리 → 승인 → 완료 리포트)은 실환경과 동일합니다.

## 1. 준비물

| 항목 | 비고 |
| --- | --- |
| Python 3.11 이상 | Windows 설치 시 **Add python.exe to PATH** 체크 |
| Git | 없으면 GitHub에서 Code → Download ZIP |
| GitHub 계정 | 저장소가 비공개라 개발자에게 아이디를 알려 초대받아야 함 |
| 터미널 2개 | ① 테스트베드, ② 사용자 앱 |

Mac은 아래 명령의 `python` 을 `python3` 로 읽습니다.

## 2. 설치 (최초 1회, 10분)

```bash
cd ~/Desktop
git clone https://github.com/newids/zero-leak.git
cd zero-leak
python -m pip install -r requirements.txt
python -m playwright install chromium        # 헤드리스 브라우저 내려받기 (몇 분)
```

Mac에서 `externally-managed-environment` 오류가 나면 pip 명령 끝에 `--break-system-packages` 를 붙입니다.

## 3. 실행 (매번)

> **Windows는 터미널 ①·② 모두, 서버를 켜기 전에 아래 한 줄을 먼저 입력합니다.**
> 한국어 Windows는 기본 인코딩이 cp949라서, 이 줄이 없으면 `detect.py`가 `vault.json`의 한글을 읽지 못해 위험 화면이 비어 나옵니다.

```powershell
$env:PYTHONUTF8="1"
```

터미널 ① — 테스트베드 (가짜 쇼핑몰·웹하드). 창을 닫지 않습니다.

```bash
cd ~/Desktop/zero-leak/testbed
python app.py                                # http://localhost:5001
```

터미널 ② — 사용자 앱 (발표 화면)

```bash
cd ~/Desktop/zero-leak/dashboard
python userapp.py                            # http://localhost:8502
```

브라우저에서 http://localhost:8502 를 열면 스마트폰 프레임 안에 앱이 뜹니다. 창 폭을 좁히면 폰 한 대처럼 보입니다.

(선택) 터미널 ③ — 관제 대시보드. 심사위원 Q&A에서 내부 동작을 보여줄 때만 씁니다.

```bash
cd ~/Desktop/zero-leak/dashboard
python -m streamlit run app.py               # http://localhost:8501
```

## 4. 데모 흐름

1. 앱을 열면 **"내 계정 보호 — 조치가 필요합니다"** 알림이 먼저 뜹니다. [확인하기]를 누르면 유출 대조가 실행되고 위험 화면으로 갑니다.
2. 위험 화면: 데모쇼핑(긴급, 그대로 일치) → 데모웹하드(주의, 변형 일치)의 도미노 그래프. **[지금 모두 처리하기]**
3. 진행 화면: '지금 Zero-Leak가 보는 화면'이 1초마다 바뀝니다. 검은 사각형이 비밀번호 입력란입니다.
4. 약 8초 뒤 승인 시트 → **[확정]**. 쇼핑몰 비밀번호 변경 완료.
5. 웹하드: 유인 팝업 2개를 지나친 뒤 다시 승인 시트 → **[확정]** (또는 [이 사이트는 건너뛰기]).
6. 완료 화면: **변경 1 · 탈퇴 1 · 소요 N초 · 비밀번호 평문 전송 0건**.

다시 돌리려면 상태바 오른쪽 **[초기화]**. 홈의 **[유출 발생 상황 보기]** 로도 2번부터 다시 시작할 수 있습니다.

승인 시트는 **30초 안에** 눌러야 합니다. 지나면 그 사이트는 시간 초과로 끝납니다 (늘리려면 5절).

## 5. 자주 쓰는 설정 (환경변수, 선택)

터미널 ②에서 앱을 띄우기 전에 넣습니다. 예: `APPROVE_TIMEOUT=120 python userapp.py` (Windows PowerShell: `$env:APPROVE_TIMEOUT="120"; python userapp.py`)

| 변수 | 기본 | 뜻 |
| --- | --- | --- |
| `APPROVE_TIMEOUT` | 30 | 승인 대기 초. 발표 연습 때 120 정도로 |
| `STEP_PAUSE_MS` | 700 | 단계 사이 멈춤(ms). 영상 녹화 때 900~1200 |

## 6. 영상 녹화

- 사용자 앱: 화면 녹화 도구(Win+Alt+R / ⌘+Shift+5)로 폰 프레임만 녹화.
- 에이전트 브라우저(커서가 움직이는 실제 화면): 새 터미널에서

```bash
cd ~/Desktop/zero-leak/agent
STEP_PAUSE_MS=900 python agent.py --all --no-confirm --record ../recordings   # recordings/*.webm
python agent.py --all --headful                                                 # 창을 띄워서 눈으로
```

## 7. 막히면

| 증상 | 확인 |
| --- | --- |
| 알림 [확인하기]를 눌러도 위험 화면이 안 뜸 | 터미널 ①이 켜져 있는지 |
| 진행 화면이 "곧 시작합니다"에서 멈춤 | `cd agent && python agent.py --all --no-confirm` 을 직접 돌려 오류 확인 (대개 Chromium 미설치·테스트베드 꺼짐) |
| 같은 화면에서 멈춤, 승인 시트 없음 | `shared/state.json` 마지막 `status`가 `handoff`면 다음 버튼을 못 찾은 것. 개발자에게 캡처 전달 |
| 승인 시트가 안 뜨고 30초 뒤 끝남 | 정상. 30초 안에 [확정] |
| `Address already in use` | 같은 앱이 이미 켜져 있음. 그 창을 Ctrl+C |
| 개발자가 고쳤다는데 그대로임 | `git pull` 후 터미널 ② 재시작 |
| (Windows) 위험 화면에 카드가 안 뜸 | 터미널 ①·②에서 `$env:PYTHONUTF8="1"` 입력 후 서버 재시작 |

사용자 앱의 '지금 Zero-Leak가 보는 화면'은 라이브 웹뷰가 아니라 에이전트가 저장한 PNG입니다. 브라우저 종류와 무관하며, 그림이 안 바뀌면 `shots/` 폴더에 파일이 쌓이는지 보면 됩니다.

## 8. 폴더 한눈에

```
zero-leak/
├─ agent/      agent.py(조작 루프) · llm.py(판단·가드레일·평문 감시) · som.js(번호 배지·마스킹)
├─ testbed/    app.py 데모쇼핑·데모웹하드 (5001) · detect.py 유출 대조
├─ dashboard/  userapp.py + userapp.html 사용자 앱 (8502) · app.py 관제 대시보드 (8501)
├─ shared/     leak.json · vault.json · risk.json · state.json · approve.flag · skip.flag · contract.md
├─ shots/      에이전트가 본 화면 PNG (커밋하지 않음)
└─ docs/       기획·안내 문서
```
